Portfolio projects aligned with collections analytics, credit risk, retail and insurance analytics, reporting automation, SQL, Python, Spark, data engineering, Excel and Power BI.

| Project | Tools | Focus |
|---|---|---|
| Collections & Recovery Analytics | SQL | Aging, recovery, RPC, prioritization |
| Credit Default & Delinquency Risk | Python | Classification, risk scoring, model comparison |
| Collections Performance Dashboard | Excel | Formula-driven KPI reporting |
| Collections & Credit Risk Dashboard | Power BI | DAX, executive reporting, drillthrough |

| [Finance Budget Variance & Contribution-Margin Model](finance_variance_model/README.md) | SQL, Python, Power BI-ready model | Multi-fact star schema; exact volume/price/cost bridge; 3,600 synthetic transactions |

All datasets are synthetic and created specifically for portfolio demonstration. No confidential employer or customer data is used.
