# Synthetic CSV data

Run `python scripts/generate_data.py` to recreate all six CSV files. The generator uses seed `20261004` and the Python standard library. Large CSVs are deliberately excluded from Git; the downloadable package includes them.

No Target customer, transaction, store, product or proprietary records are used. Store locations and merchandise are fictional. Values are USD cents, dates have no time component, and the observation period is January 1, 2024–December 31, 2025.
