# Credit Default & Delinquency Risk — Python

End-to-end classification project using synthetic collections data. The workflow compares Logistic Regression and Random Forest models and exports account-level risk scores.

On the generated holdout sample, Logistic Regression ROC-AUC is approximately 0.72 and Random Forest approximately 0.70. Results are illustrative and depend on the synthetic generation process.

Skills: Python, pandas, scikit-learn, train/test validation, classification, model comparison and risk scoring.

This is a portfolio demonstration, not a production credit decision model.
